# AI 报价查询系统 · 使用说明

一个跑在自己电脑上的报价知识库：把历史报价文件（邮件、表格、PDF、截图）整理成可检索的数据库，然后用自然语言查价、给新项目询价清单做匹配。

数据存在本地 SQLite（`data/quotes.db`），**报价数据不出本机**，仅提问时调用云端模型。

---

## 一、它能做三件事

| 功能 | 干什么用 | 在哪个页面 |
|---|---|---|
| **对话查询** | 用一句话查历史报价，如「BE22 七轴各家报价对比？」「滚床最低价是多少？」，答案附来源文件和位置 | 对话查询 |
| **清单匹配** | 上传新项目的询价清单（.xlsx），逐行匹配历史报价，生成带建议价的 Excel 草稿 | 清单匹配 |
| **数据管理** | 查看已入库了哪些文件、哪些数据需要人工复核 | 数据管理 |

---

## 二、第一次使用（只需一次）

1. **安装依赖**（需要 Python 3.12+）：
   ```
   cd quotes
   pip install -e .
   ```
2. **配置密钥**：复制 `.env.example` 为 `.env`，填入你的 API Key：
   ```
   QUOTES_API_KEY=你的Key
   ```
3. **建立知识库**（把项目文件夹里的历史报价导入数据库）：
   ```
   python -m app.ingestion.pipeline
   ```
   - 默认扫描 `config.json` 里 `data_root` 指向的目录（当前为 `raw_data/`）
   - 可重复运行：已处理过的文件会自动跳过，中断后重跑即可续传
   - 结束后在 `data/review.csv` 生成复核报告（低置信度、解析失败的文件）
   - 运行日志在 `data/logs/` 下

## 三、日常启动

双击 **`start.bat`** 即可：自动加载密钥 → 校验环境和数据库 → 启动服务 → 自动打开浏览器（`http://127.0.0.1:8000`）。

关闭那个黑窗口就是停止服务。

> 手动启动方式：`python -m uvicorn app.web.server:app --port 8000`

## 四、界面怎么用

### 1. 对话查询

- 在输入框里用自然语言提问，回车发送。常用问法：
  - 「BE22 七轴各家报价对比？」—— 多供应商横向比较
  - 「滚床最低价是多少？」—— 极值统计
  - 「伏能士焊机报过几次？」—— 按供应商计数
- 口语词会自动对应标准品类：七轴→7-Axis、涂胶→Sealing、吊具→Hoist……
- **每个价格下面有紫色「溯源」标签**，点开可以看到来源文件路径和具体位置，还能一键复制路径。
- 左侧栏有示例问题，点一下直接发送。
- 模型回答较慢时，发送键会变成「■」，点它可中止本次提问。

### 2. 清单匹配

1. 把询价清单 **拖进虚线框**（或点击选择文件），只支持 `.xlsx`
2. 点「开始匹配」，等待十几秒到几十秒
3. 结果按四档显示，可直接下载 Excel 草稿

| 档位 | 含义 | 建议价怎么来 |
|---|---|---|
| 精确匹配 | 同品类同品牌，规格相近 | 直接引用历史价（优先成交价） |
| 相似匹配 | 同品类，品牌/规格有差异 | 参考中位价 + 差异说明 |
| 弱匹配 | 仅品类相同 | 给出价格区间，**务必人工判断** |
| 无匹配 | 没有历史数据 | 留空，需发起新询价 |

清单格式要求（表头中英文均可识别）：

| 字段 | 可识别表头 | 要求 |
|---|---|---|
| 产品 | Product / Product Name / 名称 | **必需** |
| 数量 | Qty. / Qty / 数量 | **必需** |
| 规格 | Description / Descripton / 规格 | 建议有 |
| 品类 | Category / Commodity / 品类 | 建议有 |
| 品牌 | Brand / Vendor list / 品牌 | 可选 |

> **建议价仅供参考**，导出的草稿里会标记哪些行需要人工确认。最终报价由人决定。

### 3. 数据管理

- **已入库文件**：来源文件、类型、明细数量、邮件主题
- **待人工复核**：置信度低或校验有警告的记录（当前约 288 条），可按产品/供应商搜索
- 新导入了数据后，点右上角「刷新数据」

### 快捷键

| 键 | 作用 |
|---|---|
| `1` / `2` / `3` | 切换 对话查询 / 清单匹配 / 数据管理 |
| `Enter` | 发送问题 |
| `Shift + Enter` | 输入框换行 |
| `Esc` | 关闭弹窗 / 使用说明 |

## 五、常见问题

**Q：右上角显示「知识库异常」？**
服务没连上数据库。确认 `data/quotes.db` 存在；不存在就先跑一次建库管道。

**Q：提问报「尚未配置模型 API Key」？**
`.env` 里没填 `QUOTES_API_KEY`，或填了之后是在配置前启动的服务。填好后重新运行 `start.bat`。

**Q：提问报「模型服务暂时不可用」？**
网络或模型服务端问题，稍后重试。本地数据不受影响。

**Q：上传清单提示「未识别到询价清单表头」？**
检查前 10 行里是否有 Product、Qty 表头（拼写差异一般能识别，如 Descripton）。表头行之前有_merged 单元格或大标题也可能影响识别，尽量保持表头行干净。

**Q：想加新项目的报价？**
把新项目文件夹放进 `raw_data/`（或 `config.json` 里 `data_root` 指向的目录），再跑一次 `python -m app.ingestion.pipeline`，然后刷新页面。

**Q：复核报告里的 SKIP / ERROR 是什么意思？**
- `SKIP`：当前版本不支持的格式（如 .doc / .pptx），需人工看原文件
- `ERROR`：解析或调用模型时出错（如超时），重跑管道即可再试

## 六、配置速查

**`.env`**（密钥与开关，不入 git）：

| 变量 | 说明 |
|---|---|
| `QUOTES_API_KEY` | 模型 API Key（必填） |
| `QUOTES_BASE_URL` | 模型服务地址（可选） |
| `QUOTES_LOG_LEVEL` | 日志级别，排查问题时设 `DEBUG`（可选） |
| `QUOTES_LOG_FILE` | 额外日志文件路径（可选） |

**`config.json`**（系统参数）：

| 字段 | 说明 |
|---|---|
| `text_model` / `vision_model` / `embed_model` | 模型名 |
| `data_root` | 报价源文件根目录 |
| `db_path` | 数据库位置 |
| `confidence_threshold` | 低于此置信度进人工复核 |
| `workers` | 建库并行线程数 |

## 七、文件放哪了

```
quotes/
├── start.bat              ← 双击启动
├── .env                   ← 你的密钥（不进 git）
├── config.json            ← 系统配置
├── data/
│   ├── quotes.db          ← 报价知识库（所有数据都在这）
│   ├── review.csv         ← 人工复核报告
│   └── logs/              ← 建库运行日志
└── app/
    ├── ingestion/         ← 建库管道（扫描/解析/抽取/入库）
    ├── query/             ← 对话检索
    ├── matching/          ← 清单匹配
    ├── export/            ← 草稿导出
    └── web/               ← 本地网页服务与界面
```
