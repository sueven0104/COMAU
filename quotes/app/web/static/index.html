guide

使用说明

三个工作台共享同一个本地报价知识库，所有结果都能追溯到原始文件。点击下方示例可直接开始提问。

01

对话查询

像询问同事一样描述需求，系统会自动解析品类、供应商、项目与时间范围，并基于库内数据回答。

  • 支持报价对比、最低价、报价次数、价格区间等问题
  • 口语词自动映射到标准品类，如「七轴」→ 7-Axis
  • 点击答案下方的溯源标签，可查看源文件与具体位置
02

清单匹配

上传新项目询价清单后，系统逐行匹配历史报价，并生成带建议价、依据与人工确认标记的 Excel 草稿。

  • 清单需包含 Product 与 Qty 列，建议补充规格、品类与品牌
  • 匹配档位由高到低：精确匹配 → 相似匹配 → 弱匹配 → 无匹配
  • 结果页可按档位筛选、搜索并展开查看匹配说明
  • 建议价仅作参考，导出草稿中会标记需要人工确认的行
03

数据管理

这里展示知识库的文件覆盖与数据质量情况。

  • 「已入库文件」显示来源文件、类型、明细数量与邮件主题
  • 「待人工复核」汇总低置信度或校验告警的报价记录
  • 新增项目目录后可运行导入管道，刷新页面即可看到新数据
